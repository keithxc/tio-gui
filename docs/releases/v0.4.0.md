# tio-gui 0.4.0 — macOS serial tools

The macOS edition now brings the Linux serial workflow into the same compact
workspace: highlighted logs and a libvterm terminal, CRC/delayed quick sends,
the shared sequence editor, recording/rotation/replay, log analysis and graphs,
custom highlighting, session comparison, Modbus RTU and X/Y/ZMODEM transfers.
Profiles, full/portable settings, tab naming/reordering, history and shortcuts
are available. USB serial identity and new/latest selection improve reconnect.

The Apple Silicon DMG and ZIP include their runtime dependencies and use
Developer ID Application signing, hardened runtime and Apple notarization.
Built with Nix-managed dependencies through the shared macOS devShell.
Requires **macOS 26+**. Open the DMG and drag tio-gui into Applications.
The existing bundle ID and native settings location are preserved. Older native
settings migrate to preserve byte-exact append logging; imported Linux profiles
remain disconnected until you select an appropriate local device and connect.

Downloads:

- `tio-gui-0.4.0-macos-arm64.dmg` — drag-to-Applications installer.
- `tio-gui-0.4.0-macos-arm64.zip` — the same notarized application.
- `tio-gui-0.4.0-source.tar.gz` — matching application source.
- `SHA256SUMS` and `macos-0.4.0-acceptance.md` — checksums and validation scope.

Software verification covers native PTYs, binary logging, sequence ordering and
cancellation, repeated Modbus requests, all three transfer protocols in both
directions, plugin isolation/timeouts, terminal ANSI/alternate-screen/UTF-8/input,
configuration migration and recording drain on quit. Linux common-code tests
run separately in an isolated workspace.

A physical USB adapter was not available: electrical line controls, custom baud,
real unplug/replug and USB identity matching remain hardware checks. macOS has no
Linux RS-485 ioctl; use a hardware auto-direction adapter. The libvterm view has
bounded scrollback and no mouse reporting. CAN/BLE/network-only tools and Windows
feature expansion are outside this macOS serial release. Existing Linux/Windows
0.3.7 downloads are unchanged.
