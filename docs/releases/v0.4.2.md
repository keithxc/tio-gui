# tio-gui 0.4.2 — restore workspaces and preview remote serial

This prerelease supplies the Linux Nix source package and Apple Silicon
desktop packages for configuration-managed testing. It keeps GPL-3.0-only
licensing. Windows installers and mobile-native applications are not included.

## Workspace restoration

- New settings reopen the previous tabs by default, without connecting ports.
- Linux saves tab configurations independently of the startup restore option,
  including their order, individual parameters and quick commands.
- Closing the final tab preserves changed application preferences. Restoring
  logging no longer overrides a saved disabled timestamp setting.
- Existing explicit `restore-tabs=false` values remain respected. Enable
  **Reopen sessions on startup** before closing the main window if upgrading
  from an installation that previously opened only one tab.

## Remote serial preview

An optional headless native serial agent and authenticated HTTP/TLS gateway
provide browser access to a serial adapter on another computer. The browser
workspace prioritizes received output, with connection/tool drawers, a fixed
send composer and frozen selection/scrollback during continuing reception.
Linux and macOS source builds are available; Windows source compilation and
CI are included but native Windows acceptance is still pending.

This does not provide local USB serial access on iPad or Android. The gateway
must be started explicitly; the desktop app never starts a server automatically.
See [remote serial setup](https://github.com/keithxc/tio-gui/blob/v0.4.2/docs/remote-serial.md) for ownership, TLS, buffer and
background-session limits.

## Packaging and validation

Linux adds AppStream metadata and distribution build guidance. Linux, Windows
and macOS CI definitions cover their distinct source-build paths.

The macOS arm64 desktop requires macOS 26 or later. Its ZIP and DMG use
Developer ID signing, hardened runtime and Apple notarization. Package checks
do not replace physical adapter and mobile browser acceptance.

The final 0.4.2 source passed 14 Linux test groups under a virtual display,
including the close/reopen workspace regression, and 12 macOS test groups.
Both Linux Nix packages were built successfully; the agent package also ran
its three headless test groups in the Nix build.

See the [workspace restoration](https://github.com/keithxc/tio-gui/blob/v0.4.2/docs/session-restore-validation-2026-10-03.md),
[cross-platform](https://github.com/keithxc/tio-gui/blob/v0.4.2/docs/cross-platform-validation-2026-10-03.md),
and [macOS package](https://github.com/keithxc/tio-gui/blob/v0.4.2/docs/macos-0.4.2-acceptance.md)
validation reports for the tested boundaries. No general claim of every Linux distribution or five-platform
feature parity is made by this prerelease.
