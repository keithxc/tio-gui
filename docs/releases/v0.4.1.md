# tio-gui 0.4.1 — follow macOS appearance

Fixes the macOS **System** theme setting: the application now reads the macOS
appearance on startup and refreshes it while running. Version 0.4.0 only reset
a GTK preference, which could leave the interface light on a dark system.
Explicit Light/Dark choices remain fixed. The console retains the same dark
palette as the Linux serial workspace.

The build also tracks `VERSION` changes and refuses to package a stale app
version; each packaging attempt uses a fresh staging directory.

The Apple Silicon DMG and ZIP use Developer ID signing, hardened runtime and
Apple notarization. Requires **macOS 26+**. Dependencies remain Nix-managed through
`mynix#tio-gui`; the installed application requires neither Nix nor Homebrew.

Theme, serial UI and integrated serial-tools regression checks passed. The
release also includes a matching source archive, `SHA256SUMS`, and
`macos-0.4.1-acceptance.md`. See the 0.4.0 acceptance record for the full serial
feature baseline and the physical-device/Chinese IME checks still outstanding.
