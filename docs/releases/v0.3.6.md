tio-gui 0.3.6 improves console search, adds persistent font zoom, and fixes stale text during interactive shell editing.

- Hold Ctrl and scroll to resize console text. The size is shared across tabs and remembered after restarting.
- Search the active console view, navigate with Enter/Shift+Enter or F3/Shift+F3, and use case-sensitive or regular-expression matching. Highlight consoles show matching text and current/total counts while keeping the reading position stable as data arrives.
- Fix characters remaining visible after shell Backspace/Delete. The line renderer now handles delete, erase, insert and erase-to-end control sequences, verified against real Bash/Readline responses.
- Windows and macOS use the native serial edition and include their GTK/runtime dependencies. Users do not need tio, MSYS2, Homebrew or Nix.

Downloads:

- Linux x86-64: `tio-gui-0.3.6-linux-x86_64.AppImage`, including tio, runtime dependencies and Latin/CJK fonts. Make it executable and run it. Linux user namespaces are required; `--appimage-extract-and-run` is available when FUSE is unavailable. Nix users can also run `nix run github:keithxc/tio-gui/v0.3.6`.
- Windows x86-64: `tio-gui-0.3.6-windows-x86_64-setup.exe`, a per-user installer with shortcuts and uninstall support.
- macOS Apple Silicon: `tio-gui-0.3.6-macos-arm64.dmg`; drag the application into Applications. Requires macOS 26 or later. Intel Macs are not included.
- `SHA256SUMS` contains checksums for the three application packages.

The native Windows/macOS edition is a serial console and does not include the Linux edition's complete protocol/plugin toolset or a full-screen terminal emulator. USB serial drivers and hardware-specific line behavior depend on the operating system and device. Windows packages have no publisher certificate; the Mac app uses an ad-hoc signature and is not notarized.

Validation: Linux passed 10 CTest suites plus real keyboard/shell tests; the AppImage passed isolated PTY transport checks without the host Nix store. Windows installer/runtime/uninstall checks passed under Wine 11. macOS passed four native suites and a relocated bundled-app launch on an Apple Silicon Mac.
