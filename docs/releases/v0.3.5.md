tio-gui 0.3.5 improves serial output readability and makes more room for the log.

- Combine display switches, connection settings, session statistics and Clear into one row. Settings expand below; truncated statistics remain available in a tooltip.
- Reduce the highlight view's bottom spacing to approximately half a line (9 pixels).
- Update carriage-return progress in place, including backspace, horizontal cursor movement and erase-in-line sequences split across reads. Analysis records the final line when LF arrives.
- Show a blinking input caret in the highlight view, respecting remote cursor visibility, focus, text selection and paused scrolling.
- Preserve smooth following of fragmented serial output without backward jumps.

This release also publishes the development work since the previous GitHub release, v0.2.0: serial line and reconnect controls, saved send sequences, recording and replay, log analysis, isolated Lua/JavaScript plugins, file transfer, TCP/UDP, Modbus, MQTT, SocketCAN/DBC and BlueZ GATT tools, plus Chinese, Japanese and German translations.

Validation: all 10 CTest suites passed; GUI scrolling and cursor checks passed with 204 painted frames and zero backward jumps. Real keyboard-to-PTY acceptance and a Nix release build were also checked before publication.

The highlight view remains a line-oriented log view. Horizontal positions count Unicode characters; full-screen terminal applications should use the ordinary terminal view.

Build from source using the README instructions, or run with Nix:

```sh
nix run github:keithxc/tio-gui/v0.3.5
```
