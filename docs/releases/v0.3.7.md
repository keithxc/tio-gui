tio-gui 0.3.7 improves responsiveness when clearing or receiving large amounts of serial output.

- Clear highlighted history by removing text tags before deleting text. In a local 10,000-line benchmark, clear time fell from about 9.8 seconds to 0.16 seconds.
- Process the Linux raw serial stream in smaller chunks and give interface input and redraw work priority. A simulated continuously ready stream delivered all 900,000 bytes with a worst UI heartbeat gap of about 44 ms.
- Batch history trimming, limit highlighted history to 10,000 lines or 2,097,152 Unicode characters (whichever is reached first), and avoid repeated UTF-8 prefix scans while applying highlighting. Oldest complete lines are discarded when either history limit is reached; file logging is independent of this display limit.
- Preserve custom highlighting rules and search tags after clear. Regression checks cover long histories, Chinese text, partial prompts, continuous reception with clear, scrolling and selection, and real keyboard/Bash editing.
- Include the shared desktop workspace and native appearance improvements from main in all platform builds.

Downloads:

- Linux x86-64: `tio-gui-0.3.7-linux-x86_64.AppImage`, including tio, runtime dependencies and Latin/CJK fonts. Make it executable and run it. Linux user namespaces are required; use `--appimage-extract-and-run` when FUSE is unavailable. Nix users can run `nix run github:keithxc/tio-gui/v0.3.7`.
- Windows x86-64: `tio-gui-0.3.7-windows-x86_64-setup.exe`, a per-user installer with shortcuts and uninstall support.
- macOS Apple Silicon: `tio-gui-0.3.7-macos-arm64.dmg`; drag the application into Applications. Requires macOS 26 or later. Intel Macs are not included.
- `SHA256SUMS` contains checksums for the three application packages.

The native Windows/macOS edition is a serial console and does not include the Linux edition's complete protocol/plugin toolset or a full-screen terminal emulator. The history/highlight fixes are shared by all editions; the raw-stream scheduling change applies to Linux. Windows packages have no publisher certificate; the Mac app uses an ad-hoc signature and is not notarized. Performance figures are local software measurements, not hardware throughput guarantees.
