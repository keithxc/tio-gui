Session tools

  

    
    
Downloads the latest 128 KiB of received bytes. This is a buffer snapshot, not a complete recording.

    
Reading output

    
Scroll up, select text or pause to hold the display. Receiving continues. Choose Latest to return to live output.

    
Sending

    
Enter sends. Shift+Enter adds a new line. Text uses UTF-8; HEX accepts pairs of digits. Sends are limited to 64 KiB including the line ending.

    
TX counts confirmed writes. Disconnect cancels unsent data; reconnect never replays it.

    
About this connection

    
Remote serial · GPL-3.0-only · No cloud service. Text and HEX views do not interpret ANSI terminal controls. Closing or suspending the page expires control and closes the session.
